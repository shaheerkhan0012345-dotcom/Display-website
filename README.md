## Overview

**AI Build Hub** is a showcase and portfolio template built with React, TypeScript, and Tailwind CSS. It allows you to elegantly display your web applications, prompts, or design templates to the world.

### Features

- 🎨 **Beautiful UI**: Modern, glassmorphism design with a dark theme.
- 📱 **Responsive**: Works perfectly on mobile, tablet, and desktop.
- 🔍 **Search & Filter**: Find projects quickly with robust search, category filtering, and sorting capabilities.
- 📐 **Multiple Views**: Toggle between Grid and List views for your preference.
- 💾 **Local Persistence**: Saves your portfolio data locally so you don't lose it on refresh.
- ✨ **Creator Mode**: Add, edit, or delete projects directly from the UI.
- 📋 **One-Click Copy**: Easily copy prompts or share project links with a single click.

## Tech Stack

- **Framework:** React 19 + TypeScript
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Animations:** Framer Motion

## Getting Started

Follow these steps to run the app locally.

### Prerequisites

Ensure you have Node.js installed on your machine.

### Installation

1. Clone this repository.
2. Install the dependencies:
   ```bash
   npm install
   ```

### Running Locally

To start the development server:
```bash
npm run dev
```

Navigate to `http://localhost:3000` (or the port specified in your terminal) to view the app.

## Customization

You can initialize the demo dataset or export your projects directly from the UI. Modify the `src/data/initialData.ts` to set your own default showcase projects and creator profile.
